# Projeto Calculadora - Linux + Python

Este projeto contém uma calculadora feita em Shell Script e em Python.

---

## Como executar o arquivo .sh (Shell Script)

1. Dê permissão de execução:
   ```bash
   chmod 744 calculadora.sh
   
2. Execute o script
   ./calculadora.sh

3. Siga as instruções
- Digite o primeiro numero
- Digite o segundo numero
- Digite a operação
- Veja o resultado

Executar em Python :

python3 calculadora.py

- Digite o primeiro numero
- Digite o segundo numero
- Digite a operação
- Veja o resultado
